See the Java sources and report section. Put actual run captures in `evidence/` and label each image with the requirement it verifies. Never label a design mockup as a run result.

Use Java 17 or later unless the course lab prescribes another version. Compile with `javac *.java` for standalone files; run the class named in the assignment/report. Task 6 uses Maven and MySQL as documented in its README.
